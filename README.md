# MATLIB – Versioned material card repository + Abaqus plug-in

## Repository layout
```
materials/<category>/<ID>/card.inp        Abaqus *Material block (one material, name == ID)
materials/<category>/<ID>/metadata.json   version, status, units, source, approval, changelog
index.json                                 generated by CI: all metadata + sha256 per card
tools/validate_cards.py                    schema + consistency + version-bump checks
tools/build_index.py                       builds index.json
.gitlab-ci.yml                             MR validation, index publish, per-card tags (S355/v1.1.0)
abaqus_plugin/matlib/                      Abaqus/CAE plug-in
tests/test_sync.py                         sync test against a mock GitLab API
```

## Card lifecycle
1. Branch → edit `card.inp` → bump `version` (semver) and add a `changelog` entry.
2. Open MR. CI rejects it if fields are missing, *Material name ≠ ID, or the card changed without a version bump.
3. Set `status: released` + `approved_by` when the material board signs off (draft cards are hidden in the plug-in by default).
4. Merge → CI rebuilds `index.json` and tags `<ID>/v<version>`.

Version rule of thumb: patch = typo/comment, minor = added behaviour (e.g. plasticity), major = changed existing values.

## Abaqus plug-in install
1. Copy `abaqus_plugin/matlib` to `~/abaqus_plugins/` (or the site plug-in dir).
2. Edit `matlib_config.json`: `gitlab_url`, `project` (ID or `group/project`), `ref`, `model_units`.
3. Create a GitLab token with `read_repository` / `read_api` and set env var `MATLIB_TOKEN`.
4. Restart CAE → **Plug-ins > Material Library > Import Material...**

On open the plug-in pulls `index.json`, downloads only new/changed cards into `~/.matlib/cards/<ID>/<version>/`
(old versions are kept), and lists released cards. The selected card is added as `<ID>_v1-1-0`,
with id/version/sha/commit/source written to the material's Description for traceability.
If GitLab is unreachable it works from the local cache.

Scripted use (kernel / batch):
```python
import matlib_kernel
matlib_kernel.syncLibrary()
matlib_kernel.importMaterial('Model-1', 'S355 | v1.1.0 | released | SI-mm')
```
